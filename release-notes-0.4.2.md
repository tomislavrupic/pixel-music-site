# Pixel Music 0.4.2

- Preserves the companion Sirius song-draft import integration.
- Native local MCP connection for Codex and Sirius-compatible hosts.
- Settings setup for Codex, local connection test, separate access/control switches,
  visible setup progress and persistent errors.
- Versioned Sirius handoff with configuration, schemas, adapter and safe smoke test.
- Registered projects, generation/job polling, scoped cancellation and shared playback.
- Explicit generation snapshots and session-local retry protection preserve editor drafts.

MCP access starts disabled. Keep Pixel Music open; connect from Settings →
Codex & Sirius. Sirius registration is exported for integration, not automatically
installed. No live model generation or listening-quality claims are part of this release.
